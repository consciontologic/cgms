# Font provenance

These unchanged upstream fonts provide the live rank and text overlays for this art exploration. They are bundled locally; no system installation or runtime font service is required. Both families are distributed under SIL Open Font License 1.1. Full, unmodified copyright and license notices are retained beside the fonts; authors and contributor notices are included too.

Barlow Condensed Bold supplies rank labels. Atkinson Hyperlegible Next Regular and Bold supply captions and readable supporting labels. Family names are retained because the font binaries have not been modified.

The official repository trees were discovered with GitHub's API. Each content response supplied its download URL at the pinned commit below. Downloaded bytes were checked against the API's Git blob SHA, and SHA-256 checksums are recorded below.

## Use and preservation

Keep each family's OFL notice with any redistributed font files. The font software remains under OFL; the repository's MIT license does not replace the font licenses. The notices describe the permitted embedding, redistribution and modification conditions.

These files add exploration-only typography. No accepted production asset or existing art-direction skill has been replaced.
