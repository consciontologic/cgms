# Historical rules drafts

Current gameplay is defined only by [GAME_RULES.md](../../project/GAME_RULES.md).
These four drafts are historical snapshots; their open questions and current-authority
wording in retained rule bodies do not override the canonical rules.

| Draft | Historical role |
|---|---|
| [FIRST_DRAFT.md](FIRST_DRAFT.md) | First structured rules reference. |
| [SECOND_DRAFT.md](SECOND_DRAFT.md) | Second consolidated rules draft. |
| [THIRD_DRAFT.md](THIRD_DRAFT.md) | Source for the accepted Q01–Q12 finalization. |
| [FINAL_DRAFT.md](FINAL_DRAFT.md) | Q01–Q12/F01–F10/N01–N07 snapshot before T01–T03, now incorporated into canonical GAME_RULES. |

All four were relocated on 2026-09-28. Only their authority notices and relative
links were adjusted; historical rule bodies were not rewritten. The archived
final draft is the last reviewed draft, not a second current rules file.
